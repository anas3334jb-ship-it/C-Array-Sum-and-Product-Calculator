# C++ Array Sum and Product Calculator

A simple and efficient C++ program to calculate the sum and product of elements in an integer array using modular functions and a while loop.

---

## Repository Details
* **Suggested Repository Title:** `cpp-array-sum-product`
* **Suggested Description:** A C++ console application that computes the sum and product of array elements using clean, modular functions.

---

## Project Overview
This C++ program defines two separate functions (`sum` and `product`) that take an integer array and its size as parameters. It iterates through the array using a `while` loop to compute the total sum and product of all elements, then displays the results in the console.

## Code Features
* **Modular Design:** Uses distinct functions for calculating the sum and product, promoting code reusability and cleanliness.
* **While Loop Iteration:** Efficiently traverses array indices from start to size.
* **Standard I/O:** Uses `<iostream>` for clear console output.
